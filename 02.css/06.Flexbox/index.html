Flex container is one dimentional.

Items flow along the vertical axis by default or when out of horizontal space to move to the next row.

display:flex. Enable a flex container.
justify-content. For item alignment on main axis (horizontal).
align-items. For item alignment on cross axis (vertical).

flex-wrap: For item wrapping on the next row.
align-content. Used for packing flex lines and control over space.
flex-direction. For specifiying if items aling on rows or columns.
flex-flow. Combines flex-direction and flex-wrap into one property.
flex-gap. For adding a gap between items. Use this instead of margin.
align-self. For uniquelu aligning flex items on cross axis.
order. For manually ordering items.
flex-grow. Specifies how fast an item grows compared to the other items in the flex container.
flex-shrink. Specifies how fast an item shrinks compared to the other items in the flex container.
flex-basis. Specifies the size after which grow or shink is applied to the item.
flex. Combines flex-grow, flex-shrink and flex-basis into one property.

No flexbox

Display is block by default. Items align on a column like blocks on top of each other.

Items 100% width

Flex units

Flex-Grow

Item set with flex-grow grows up to all of the available space.

The higher the number the faster it grows compared to other items.

Slowly shrink and grow the browser window to observe the behaviour.

Flex-Grow fixed(0)

Flex-Shrink

Defines how fast an item shrinks compared to others.

It is reversed as grow. The higher the number the faster it shrinks.
